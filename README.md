# Create: Trackwright

Smarter track laying for Create: Placement guides, tunnels through rock, undo, and train fixes

## Compatibility

| Component | Version |
| --- | --- |
| Minecraft | `1.21.1` |
| Mod loader | NeoForge `21.1.248` or newer |
| Create | `6.0.10` |
| Java | `21` or newer |
| Environments | Client and server |

## Download

- [CurseForge](https://www.curseforge.com/minecraft/mc-mods/trackwright)
- [GitHub releases](https://github.com/chaevsfe/Trackwright/releases)


## Building

```
git clone https://github.com/chaevsfe/Trackwright
cd Trackwright
./gradlew build
```

Requires JDK 21.
